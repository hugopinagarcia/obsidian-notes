- CAP MCP - https://github.com/cap-js/mcp-server
	- By default, this MCP server is designed to run locally in IDEs (like VS Code) communicating over standard input/output (**stdio**). To allow a cloud AI agent to access it via a URL on SAP BTP, it must exposed over HTTP using Server-Sent Events (**SSE**).
